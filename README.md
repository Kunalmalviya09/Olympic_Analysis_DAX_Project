# 🏅 Olympic Games Data Analysis | Power BI

## 📌 Project Overview
An interactive **6-page Power BI dashboard** developed to analyze historical Olympic data, uncover country-wise medal trends, evaluate athlete performance, and explore sports dominance and athlete demographics.

## 🎯 Project Objectives
- Analyze global Olympic medal trends.
- Evaluate country-wise and athlete-level performance.
- Identify top-performing countries, athletes, and sports.
- Analyze host country performance.
- Explore gender distribution and athlete demographics.

## 🛠️ Tools & Technologies
- **Power BI Desktop** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and columns.
- **Data Modeling** – Table relationships and Calendar table.

## 📊 Dashboard Pages

| Page | Analysis |
|---|---|
| 1. Global Medal Overview | Total medals, participating countries, top 10 countries, medal trends, and yearly events. |
| 2. Country Insights | Athletes, medals, medal efficiency, medal distribution, and best-performing sports. |
| 3. Athlete Spotlight | Top athletes, Olympic appearances, medal winners, age, and gender distribution. |
| 4. Sport & Event Analysis | Total sports/events, events added, sport-wise medals, participation, and country dominance. |
| 5. Host Country Analysis | Olympics hosted, host vs non-host medals, and host country performance trends. |
| 6. Gender & Demographics | Gender participation, medal distribution, age analysis, and age-group participation. |

## ⚙️ Power BI Concepts Implemented
- DAX Measures & Calculated Columns
- Data Modeling & Relationships
- Power Query Transformations
- Interactive Charts & Visualizations
- KPI Cards, Tables & Matrix
- Slicers & Filters
- What-If Parameters
- Top N Ranking Analysis
